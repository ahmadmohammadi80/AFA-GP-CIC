# AFA-GP-CIC — بسته کنترل عددی و صراحت پیچیدگی نمونه

این افزونه را در کنار فایل‌های مرحله `research/certified_completion_20261116` استفاده کنید.

```bash
python -m pip install numpy scipy mpmath
python -m unittest discover -s research/verified_closure_20261116 -p 'test_closure.py' -v
```

- `validated_enclosures.py`: تبدیل سیاست به بردار دقیق گویای جمع=۱؛ بررسی بازه‌ای KL و کران بالای دوگان؛ کران پایین با اعداد گویا.
- `verified_solver.py`: رابط fail-closed بهینه‌ساز و گواهی؛ در صورت شکاف زیاد استثناء می‌دهد.
- `sample_complexity.py`: رابطه صریح برای تعداد نمونه یکنواخت و سربار اکتشاف اجباری.
- `test_closure.py`: آزمون‌های تصادفی، مرزی، دقت و نظریه.
- `PROOF_CLOSURE_FA.md`: استدلال ریاضی و فرضیات.

`mpmath.iv` یک ابزار حساب بازه‌ای مستقل از ارزیابی float64 حل‌گر است. اعتبار خروجی به این کتابخانه و نحوه تبدیل سیاست به کسر وابسته است؛ گواهی رسمی متکی بر اثبات ماشینی همه اجزای نرم‌افزار تولید نشده است. الگوریتم در دامنه ترجیحات ایستا و کنش‌های محدود ارزیابی شده است.
