# AFA-GP-CIC: تکمیل الگوریتم و اثبات (نسخهٔ محدودِ متناهی)

## چه چیزی اصلاح شد؟

- `certified_solver.py`: حل‌گر KL مقاوم با **کران پایین سیاست مجاز، کران بالای دوگان و شکاف قابل‌ممیزی**؛ تشخیص دقیق مسئله‌هایی که همهٔ بازه‌های اطمینان اشتراک دارند و بهترین گواهی آنها صفر است.
- `strong_adaptive_study.py`: اتصال حل‌گر به آزمایش‌های قبلی و حفظ API قدیمی؛ گزارش فاصله دوگان در تمام آزمایش‌ها.
- `adaptive_certification.py`: کنترل‌گر آنلاین انتخاب تطبیقی پاسخ، مشاهدهٔ ترجیح، به‌روزرسانی گواهی و توقف ایمن.
- `real_llm_pilot.py`: ثبت شکاف بهینگی همراه با خروجی هر سؤال و گزارش کیفیت محدود؛ **رأی‌ها همچنان برنامه‌نویسی‌شده‌اند، نه انسانی.**
- اصلاح مهم شعاع هوفدینگ برای مشاهدات `[-1,1]`: استفاده از سقف **۲ به‌جای ۱**؛ اعتبار بازه‌های نمونه کم به این اصلاح وابسته است.

## تعریف دقیق «کامل» در این نسخه

کدها و پنج قضیه بر اساس فرضیات نوشته‌شده در `PROOF_COMPLETE_FA.md` بررسی می‌شوند. هر خروجی با دو معیار جداگانه ارزیابی می‌شود: **صحت گواهی آماری** و **فاصله بهینگی عددی**. وضعیت موفق یک آزمایش، اثبات برتری جهانی در نوآوری یا آزمون ترجیحات انسانی نیست.

## دستورهای اجرایی

```bash
python -m pip install numpy scipy
python -m unittest discover -s tests -v
python strong_adaptive_study.py --ks 6 12 24 48 --n 5000 --seeds 40 --out cyclic_study_certified.json
# پایلوت با مدل واقعی، در محیط دارای شبکه و وزن‌های Hugging Face:
python -m pip install torch 'transformers>=4.47,<5' huggingface_hub
python real_llm_pilot.py --out real_llm_certified.json --n 5000
```

پوشش آزمون‌ها: محیط ثابت غیرتراگذر، مقایسه با جواب اوراکل، ۴۵ نمونه تصادفی بهینه‌سازی، حالات بدون امکان بهبود، حالات KL=0، بازه‌های هم‌زمان و توقف تطبیقی.
