# بررسی مقدماتی پیشینه و تمایز

**این ماتریس یک ممیزی محدود پژوهشی است و اثبات نبود الگوریتم مشابه در کل جهان نیست.**

| روش پیشین | بخش مرتبط | وضعیت تمایز |
|---|---|---|
| POSTPI (RLC 2025) | پذیرش سیاست با آزمون بهبود دارای اطمینان بالا | CA-VOI داده را برای خود گواهی انتخاب می‌کند؛ مقایسه رسمی با POSTPI+انتخاب فعال کامل نشده |
| APO (2024) | جمع‌آوری فعال ترجیحات برای RLHF | انتخاب جفت به هدف نرخ برد گواهی‌دار مرتبط است؛ تقدم جهانی این هدف روشن نیست |
| PILAF (ICML 2025) | نمونه‌گیری آگاه از سیاست | CA-VOI به صدور گواهی تمرکز دارد، نه خطای تخمین کامل پاداش |
| Nash Learning from Human Feedback (ICML 2024) | ترجیحات عمومی و چرخه‌ای | مدل چرخه‌ای به‌تنهایی سهم تازه AFA محسوب نمی‌شود |
| ActiveDPO / ADPO | انتخاب داده وابسته به سیاست | برای اثبات استقلال نوآوری باید قواعد اجرایی و پیچیدگی نمونه مقایسه شوند |

مراجع اولیه: [POSTPI](https://rlj.org/papers/tse2025high)، [APO](https://arxiv.org/abs/2402.10500)، [PILAF](https://proceedings.mlr.press/v267/feng25g.html)، [Nash Learning](https://proceedings.mlr.press/v235/munos24a.html).

**نتیجه:** کپی عینی الگوریتم در منابع منتخب شناسایی نشده است. هم‌پوشانی مفهوم و اجزا وجود دارد؛ تأیید بی‌سابقگی و مزیت مستقل نیازمند مقایسه مستقیم است.
