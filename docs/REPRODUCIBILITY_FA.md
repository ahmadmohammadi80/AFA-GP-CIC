# شواهد بازتولید ۱۶ نوامبر ۲۰۲۶ (محیط مصنوعی)

نسخه benchmark: seedهای 120..219، پنج پاسخ، ده جفت، بودجه ۱۵۰۰ مشاهده، پایلوت ۲۵ برای هر جفت، kappa=0.25، delta=0.05.

| روش | تعداد صدور گواهی از ۱۰۰ | میانگین مقایسه |
|---|---:|---:|
| CA-VOI با انتخاب دوباره نامزد | ۲۹ | ۱۴۰۶٫۵ |
| CA-VOI با نامزد ثابت | ۲۸ | ۱۴۰۹٫۰ |
| روش کاهش پهنا و انتخاب تطبیقی | ۲۱ | ۱۴۵۲٫۹ |
| روش کاهش پهنا و نامزد ثابت | ۲۱ | ۱۴۵۰٫۷ |
| روش انتخاب بر اساس واریانس | ۰ | ۱۵۰۰ |
| تخصیص یکنواخت | ۰ | ۱۵۰۰ |

نتایج ثبت‌شده: ۱۸ آزمون واحد موفق و ۲۰۰ کنترل منفی چرخه‌ای بدون پذیرش مثبت اشتباه **مشاهده‌شده**. صفر مشاهده، به معنای صفر بودن احتمال خطا نیست. اختلاف CA-VOI با روش کاهش پهنا در نمونه جفتی: p=0.0078125؛ اختلاف ۲۹ و ۲۸ برای نامزد متغیر و ثابت معنادار نبود.

در آزمایش جداگانه lookahead دومرحله‌ای، مزیت نسبت به انتخاب حریصانه مشاهده شد، اما یک رقیب ثابتِ مطلع نیز همان نتیجه را بازتولید می‌کند.

## بازتولید

```bash
pip install -r src/cert_voi/requirements.txt
python src/cert_voi/test_joint.py
python src/lookahead/test_finite_horizon.py
python src/cert_voi/benchmark.py --start 120 --end 220 --out results_120_220.json
python src/cert_voi/null_stress.py
```

خروجی خام حجیم و هش‌های آرشیو کامل در بسته پژوهشی اصلی نگهداری شده‌اند؛ این مخزن صرفاً کد و خلاصه ثبت‌شده را دارد تا از بارگذاری ناخواسته داده‌های مصنوعی حجیم اجتناب شود.
